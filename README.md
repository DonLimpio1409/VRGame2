VR Rage Room
Descripción
VR Rage Room es una experiencia de realidad virtual desarrollada en Unreal Engine que permite a los jugadores liberar estrés en un entorno seguro e inmersivo. El objetivo es interactuar con distintos objetos de la sala utilizando herramientas físicas y destruir el mobiliario, decoraciones y elementos del escenario aprovechando las mecánicas de realidad virtual.

La experiencia se centra en ofrecer una sensación satisfactoria de impacto y destrucción mediante interacciones realistas, permitiendo al usuario explorar el entorno y utilizar diferentes objetos para causar el mayor caos posible.

Entorno de juego
La sala contiene diferentes elementos decorativos y mobiliario que el jugador puede destruir. Entre ellos se incluyen camas, estatuas, jarrones y otros objetos distribuidos por el escenario para crear una experiencia de destrucción variada y entretenida.
